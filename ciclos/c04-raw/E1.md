## MECANISMO
**Hipótesis.** GJR-GARCH con σ_t función fija del pasado; innovaciones z de varianza 1 y densidad f; M2 = κ_f·Q(θ) + 2β(α+γ/2) + β², κ_f=E[z⁴]. **La fase depende de f SOLO a través de κ_f.**
**Lema (exacto, no asintótico).** Con el mismo θ y el mismo σ₁, p_i = ∏_t σ_t⁻¹f_i(x_t/σ_t) con σ_t idéntico. Integrando hacia atrás, cada afinidad condicional vale ρ(f₀,f₁) independientemente del pasado: **afinidad_T = ρ^T exactamente.**
**Construcción.** f₁ = renormalización de (1−ε)f₀ + ε·bump(±M). H²(f₀,f₁) ≤ ε + O(ε²M⁴); Δκ ≈ εM⁴. Con ε=c/T y M=(Δκ·T/c)^¼: ρ^T ≥ e^(−c/2) y **Δκ no depende de T**.
**Teorema.** Para toda brecha fija D>0 hay dos leyes con M2 = 1∓D/2, TV ≤ √(1−ρ^{2T}) < 1, y error minimax ≥ ½(1−TV) > 0 **para todo T**. Numérico: ≥0,246 con D=0,02, invariante de 10 a 32.000 años.
**Dónde falla la versión pedida en N30.** Un argumento de dos puntos *en θ* no puede dar N24: el modelo es regular, luego a=1/2 y la ventana indecidible se encoge. **La irregularidad no está en θ; está en f.**
