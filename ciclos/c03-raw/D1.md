## MECANISMO
Sea v_t estacionaria con ρ(k)≈c·k^(2d−1); Var(Σ_{t≤n}v_t)=σ²S(n), S(n)≈2c·n^(1+2d)/[2d(2d+1)].
  Aleatorio:  CV(IV_H) = σ√S(n_H)/(θ·n_H) ∝ H^(d−½)
  Epistémico: sd(θ̂_T)/θ = σ√S(n_T)/(θ·n_T) ∝ T^(d−½)
**Misma función, distinto argumento** ⇒ R = epistémico/aleatorio = **(H/T)^(½−d)**.
Se cancelan σ, θ, c, τ y la unidad de muestreo. **R=1 ⟺ H=T para todo d.**
**n_eff ≡ 1/R² = (T/H)^(1−2d) ≤ T/H.**
Rango de Hermite m: n_eff^(m)=(T/H)^min(1, m(1−2d)); satura en el muro si d ≤ d*_m=½(1−1/m).
Error de N22: promediar dentro de H mejora θ̂ por H/τ, pero IV_H se concentra por ese mismo H/τ. Son el mismo factor.
**Corolario: T_eff = H^(2d)·T^(1−2d)**, no T^(1−2d).
